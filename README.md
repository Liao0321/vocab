# 英文單詞練習

給學生用的中英文單字練習網站。老師匯入單字，系統自動出題、評分；學生用 Google 帳號登入，有自己的練習紀錄。

- **網站主機**：GitHub Pages（免費）
- **登入與資料庫**：Firebase 免費方案（Spark），用 Google 登入和 Firestore 資料庫
- **不需要** Firebase Storage，也不用綁信用卡。圖片和音檔會壓縮後直接存在 Firestore。

還沒設定 Firebase 時，網站會以「示範模式」執行，可以選「我是學生」或「我是老師」先試用。資料只會存在那台電腦的瀏覽器裡。

---

## 功能

**學生**
- 學生不用選字卡組：所有「已發布」字卡組的單字放在一起出題。
- 首頁七個按鈕：圖片題、聲音題、配對題、拼字題、手寫題、綜合挑戰（前四種輪流），以及練習模式（隨機順序播放全部字卡，不計分）。
- 答錯時會顯示正確答案，並重複播放發音。答錯的字會自動排到這一輪最後，換過選項順序再考，直到答對為止；還沒訂正完不能結束這一輪。
- 平板和筆電會顯示較大的選項；筆電可以用鍵盤 1–4 作答、Enter 下一題。
- 每回合 10 題，另外穿插最多 4 題自己常錯的字。
- 右上角的人頭圖示是「個人練習紀錄」：連續練習天數、近 30 天平均每天練習題數、16 週練習熱度圖、最不熟的單字（可一鍵專練）、最近練習、手寫作業批改結果。登出按鈕在這一頁的最下方。
- 選擇題和配對題的錯誤選項會挑「很像」的字：開頭或字尾相同、拼法或發音接近、中文翻譯有同一個字、詞性相同。

**老師**
- 建立字卡組，可以一個一個新增，或用 Excel／CSV 批次匯入，並一次選取音檔和圖片。
- 欄位：中文單詞、英文單詞、詞性、音標（有音標符號小鍵盤）、中文音檔、英文音檔、輔助圖片。
- 英文欄也可以放句子（例如 How's the weather in Taipei?）。手寫題是單行四線格，寫到右邊時按右側的三角形，手寫區會往右滑，左邊剛寫的字仍看得到，也能滑回左邊。交出的作業圖片裡，每題的字大小一致，空白處會自動裁掉。
- 沒有音檔的字，會用學生裝置內建的語音念出來。
- 字卡組只是老師整理單字用的。勾選「發布」的字卡組，單字才會出現在學生的練習裡；取消發布就會暫時拿掉。
- 「手寫作業」頁面：逐題打 ✓／✗，也可以下載圖片。批改結果會出現在學生的紀錄裡，寫錯的字會變成學生的「常錯的字」。

## 第一次設定（大約 20 分鐘）

### 1. 建立 Firebase 專案
1. 到 <https://console.firebase.google.com/>，按「建立專案」，名稱自訂（例如 `vocab-class`）。Google Analytics 可以關掉。
2. 專案建好後，在首頁按「</>」（網頁）圖示新增應用程式，暱稱自訂，**不用**勾選 Firebase Hosting。
3. 畫面會出現一段 `const firebaseConfig = { ... }`。把大括號裡的內容貼到 `js/config.js`，取代 `null`：

   ```js
   export const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "vocab-class.firebaseapp.com",
     projectId: "vocab-class",
     storageBucket: "vocab-class.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
   這段設定公開在網站上是正常的。資料安全是靠第 4 步的安全規則把關。

### 2. 開啟 Google 登入
1. 左側選單「建構 → Authentication」→「開始使用」。
2. 「登入方式」分頁 → 選 **Google** → 啟用 → 填支援電子郵件 → 儲存。
3. 「設定」分頁 →「授權網域」→ 新增你的 GitHub Pages 網域，例如 `你的帳號.github.io`。

### 3. 建立 Firestore 資料庫
1. 左側選單「建構 → Firestore Database」→「建立資料庫」。
2. 位置建議選 `asia-east1（台灣）`。
3. 選「以正式版模式啟動」。

### 4. 貼上安全規則
1. 在 Firestore 的「規則」分頁，把畫面上的內容全部刪掉。
2. 貼上本資料夾的 `firestore.rules` 全部內容，按「發布」。

### 5. 設定老師名單
1. 在 Firestore 的「資料」分頁，按「開始集合」，集合 ID 填 `teachers`。
2. 文件 ID 填老師的 Gmail，**全部小寫**，例如 `wang.teacher@gmail.com`。
3. 新增一個欄位：名稱 `name`，類型「字串」，值填老師的名字，按儲存。
4. 有其他老師的話，再「新增文件」，做法相同。

不在名單上的 Google 帳號登入後只能練習，不能建立或修改字卡組。這是由資料庫規則把關，就算有人改了網頁程式也繞不過去。

### 6. 放上 GitHub Pages
1. 在 GitHub 建立一個新的 repository（公開），例如 `vocab`。
2. 把這個資料夾的所有檔案上傳到 repository 的根目錄：`index.html`、`css/`、`js/` 等。
3. repository 的「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/vocab/`。

### 7. 試用
1. 用老師的 Google 帳號登入，上方應該會出現「管理字卡組」和「手寫作業」。
2. 建立一個字卡組，加幾個單字，勾「發布給學生」並儲存。
3. 用另一個 Google 帳號登入，應該能看到這個字卡組並開始練習。

## 批次匯入格式

第一列是標題列。可以從 Excel 或 Google 試算表直接複製貼上，也可以存成 CSV 上傳（Excel 的「CSV UTF-8」或一般 CSV 都可以）。

| 中文 | 英文 | 詞性 | 音標 | 中文音檔 | 英文音檔 | 圖片 |
|---|---|---|---|---|---|---|
| 蘋果 | apple | n. | /ˈæp.əl/ | apple_zh.mp3 | apple.mp3 | apple.jpg |
| 跑 | run | v. | /rʌn/ | | | |

- 音檔和圖片欄填**檔名**，匯入時把這些檔案一起選進來。
- 檔名欄空白時，系統會自動找同名檔案：英文音檔找 `apple.mp3`，中文音檔找 `蘋果.mp3` 或 `apple_zh.mp3`，圖片找 `apple.jpg`／`apple.png`。
- `sample-import.csv` 是範本。

**檔案大小**：圖片會自動縮小到 480 像素。每個音檔要在 300KB 以內（一個單字的 MP3 通常只有 10–50KB）。

## 免費額度夠不夠用？

Firestore 免費方案每天有 5 萬次讀取、2 萬次寫入，總容量 1GiB。

- 學生打開一個 30 字的字卡組，大約讀取 30 次。
- 練完一回合，大約寫入 15 次。
- 一份手寫作業圖片大約 60–150KB。

一個班 30 位學生，每人每天練 5 回合，大約每天 4,500 次讀取、2,250 次寫入，離上限很遠。手寫作業累積很多時，可以在「手寫作業」頁面刪除舊的。

## 常見問題

- **學生在 LINE 裡點連結，不能登入**：LINE、Facebook 的內建瀏覽器不允許 Google 登入。請學生點右上角選單，選「用瀏覽器開啟」。網站也會顯示這個提示。
- **沒有聲音**：iPhone／iPad 請把側邊的靜音開關打開。沒有上傳音檔的字，會用裝置內建的語音念；有些電腦需要在系統設定裡安裝英文或中文語音。
- **老師登入後沒有「管理字卡組」**：確認 `teachers` 集合的文件 ID 和登入的 Gmail 完全一樣，而且全部小寫。
- **練習紀錄存在哪裡**：每位學生的紀錄存在 Firestore 的 `users/{學生編號}` 底下。老師可以在 Firebase 主控台查看。
